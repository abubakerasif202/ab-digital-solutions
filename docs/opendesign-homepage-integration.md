## 7. Evidence

- Playwright (Chromium) `tests/e2e/luxury-homepage.spec.mjs`: **17/17 pass.** Viewports 360×800, 390×844, 820×1180, 1440×900, 1920×1080 (no horizontal overflow, no console errors, every image loads); real contact and profile links; heading order, landmarks, unique ids, labels; filters and counts; dialog focus and Escape; mobile menu; form validation, real-contract POST, failure never shown as success; keyboard and focus rings; reduced motion; no-JavaScript fallback.
- Node guards `tests/luxury-homepage.test.mjs`: **8/8 pass** (data in sync with registry, no placeholder contact, accepted services, live-label evidence, real images, no third-party hosts, AA contrast of 16 token pairs).
- `npm run verify` (lint, typecheck, 213 tests): **pass.**
- Performance (390 px, cold): **714 KB** initial transfer, layout shift **0.0000** after a full scroll. Below-the-fold images lazy-load. These are single local runs, not a Lighthouse score.
- Screenshots (git-ignored): `test-results/opendesign-homepage/screenshots/{original,corrected}/` — five full-page and hero captures per version, plus work grid, dialog, form errors and mobile menu.

## 8. Limits

- Chromium only; Firefox and Safari not run. No axe or Lighthouse run (adding a dependency is a delivery decision). Contrast is asserted for tokens, not for every rendered pair.
- The prototype needs JavaScript for the work grid and form. The Next port in Stage 2 renders them on the server.
- Fonts in `opendesign/luxury-homepage/fonts/` (OFL, latin subset) exist only for the standalone build; Stage 2 uses `next/font`.
- The prototype's `/api/contact` is a stub that answers 503, so no email is sent from it.
