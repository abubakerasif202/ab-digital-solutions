## Prompt A: Initial safe prototype (use first)

Create a standalone, high-fidelity, mobile-first interactive homepage prototype for AB Web Studio, a premium Sydney web development and digital solutions agency. Apply the custom design system **AB Web Studio — Gilt & Ruby** from the active DESIGN.md and tokens.css. The atmosphere is cinematic midnight black, antique gold and ruby, with refined editorial Bodoni Moda headlines, Schibsted Grotesk body copy and IBM Plex Mono labels. Produce a polished responsive homepage that includes: a large editorial hero with striking AB monogram and Sydney skyline concept, clear CTA to start a project, design/development/SEO service areas, selected work previews, a concise process timeline, an elegant enquiry section, footer with social links, and genuine responsive mobile navigation. Include detailed hover/focus states, restrained GSAP-style motion only where supported, reduced-motion fallback, keyboard access and meaningful imagery. Use realistic content, but do not invent awards, reviews, client logos or results. Build in this OpenDesign prototype project ONLY. DO NOT edit, overwrite, commit, push, or deploy anything in the existing C:\Users\abuba\ab-digital-solutions website repository. Deliver a preview, mobile/desktop evaluation and the source artifact, and identify any content assumptions.
