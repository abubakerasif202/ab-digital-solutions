# AB Digital Solutions — Premium Portfolio

A responsive, dependency-free portfolio website using the supplied AB Digital Solutions logo and black-and-gold brand artwork.

## Preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Included

- Responsive desktop, tablet and mobile layouts
- Accessible navigation, keyboard focus states and reduced-motion support
- AB Digital Solutions logo across the header, about section, footer and favicon
- Services, selected work, process, studio standards and contact sections
- Phone, email and WhatsApp contact options
- SEO metadata, social sharing metadata and basic structured business data
- Contact form that opens the visitor's email application with the enquiry pre-filled

## Before publishing

- Add a canonical URL once the final domain is confirmed.
- Replace the email fallback with a hosted form endpoint if enquiries should submit without opening an email app.
- Add verified project screenshots when they are available.
- Add privacy-policy and analytics-consent pages if analytics or tracking tools are introduced.
